# Anagrams

## Overview
A Java program that uses hash tables and prime-based hashing to identify and group words that are anagrams of one another.

## Features
- Identifies words with matching anagrams.
- Uses hash tables for efficient grouping.
- Implements prime-based hashing.
- Processes dictionary files to identify groups of anagrams.

## Technologies
- Java
- Hash Tables
- Hashing Algorithms
- Data Structures
